# 7鬼523斗地主变体

Copyright © 2026 32%Hcl 陈龙大王

一个两人对战的扑克牌游戏，支持 AI 对战和关卡模式。

---

## 如何运行

### 方式一：下载 Release

1. 下载 `7gui523-win64.zip`
2. 解压到任意目录
3. 双击 `game.exe` 运行

### 方式二：从源码编译

需要 CMake 3.16+、C++17 编译器。Qt 6 可选（仅 GUI 需要）。

**完整编译（含 GUI）：**
```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="C:/Qt/6.x/mingw_64"
cmake --build build --target game unit_tests ai_vs_ai all_vs_all
ctest --test-dir build --output-on-failure
```

**仅编译核心规则和 AI（无 Qt）：**
```powershell
cmake -S . -B build -G Ninja -DBUILD_GUI=OFF -DCMAKE_BUILD_TYPE=Release
cmake --build build --target unit_tests ai_vs_ai all_vs_all
```

**运行测试：**
```powershell
# 单元测试（25项）
.\build\unit_tests.exe

# AI vs AI 对战（80局）
.\build\ai_vs_ai.exe

# 关卡通关率（100局）
.\build\all_vs_all.exe
```

Windows 使用 MSVC 时，请先打开 Visual Studio 的 x64 Native Tools 命令行。

## 操作说明

### 开局先手选择
- **先手** — 玩家先出牌
- **随机** — 随机决定谁先出
- **后手** — AI 先出牌

### 选卡
点击"选卡"打开卡牌选择界面，点选卡牌加入起始手牌。
- 可选 **0~5 张**，未选满的位置由牌堆随机补全
- 点击已选卡牌可移除

### 出牌
点击手牌选中，点"出牌"。支持的牌型：
单张、对子、三张、三带一、三带二、炸弹（四张相同点数）、王炸（大鬼+小鬼）、Special523（7+鬼+5+2+3，最高优先级）。

### 不要
点"不要"跳过本回合。

### 难度
循环切换四档 AI 难度：
AI1 简单 → AI2 规则 → AI3 记牌 → AI4 专家 → AI1 简单

### 关卡模式
6 个 Boss 关卡，每个 Boss 有特殊能力：
- **新手**：永远出最小单张
- **换牌虫**：开局将牌堆中的 4/6 随机换成其他点数
- **急眼雀**：Boss 始终先手
- **疯狗**：每次出牌造成 出牌数×3 伤害（扣玩家分数）
- **赖账鬼**：玩家不能用相同点数压牌；Boss 可用同花色任意单张压制
- **不识数**：Boss 无法压制时 50% 概率强行出最小单张；50% 概率牌型相同即可压

## 牌序

从大到小：7 > 大鬼 > 小鬼 > 5 > 2 > 3 > A > K > Q > J > 10 > 9 > 8 > 6 > 4

## 牌型

单张、对子、三张、三带一、三带二、炸弹（四张相同点数）、王炸（大鬼+小鬼）、Special523（7+鬼+5+2+3，最高优先级）。

顺子、连对、飞机等不合法。

## 玩法

- 每人起始 5 张手牌，从牌堆补牌
- 一方出牌后，另一方出同点数或更大的同牌型，或出炸弹/王炸，或选择"不要"
- 一方要不起，本回合结束。胜方优先补牌至 5 张，败方后补
- 牌堆抽空后当前回合继续；回合结束发现牌堆空，进入终局阶段。终局阶段出完立即结算
- 终局结算：出完牌者获得桌面分值卡、累计压分奖励与对方手牌分值卡
- 分值卡：5 = 5 分，10 = 10 分，K = 20 分
- 最终比较总分，同分平局

## 特殊胜利

**一次性打出** 7 + 鬼（大鬼/小鬼均可）+ 5 + 2 + 3 这 **5 张牌**，直接获胜，不结算分数。

（注意：不是手牌里凑齐就算，必须一次性打出。）

## 压分奖励

出 5 / 10 / K 的单张或对子（含三带一、三带二中的 5/10/K）时，如果和上一手**同牌型、同点数**，额外获得本次出牌的分值。

例如：上一手出了单张 5，这一手也出单张 5，则额外获得 5 分。

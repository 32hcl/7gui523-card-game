# 7鬼523斗牌游戏

Copyright © 2026 32%Hcl 陈龙大王

一个两人对战的扑克牌游戏。

操作
选卡：游戏开始时点击"选卡"自定义起始手牌

出牌：点击手牌选中，点"出牌"

不要：点"不要"跳过本回合

难度：循环切换 AI1 / AI2 / AI3

重新开始：重开一局

## 牌序

从大到小：7 > 大鬼 > 小鬼 > 5 > 2 > 3 > A > K > Q > J > 10 > 9 > 8 > 6 > 4

## 牌型

- 单张
- 对子
- 三张
- 三带一
- 三带二
- 炸弹
- 王炸（最大）

顺子、连对、飞机等不合法。

## 玩法

- 每人 5 张手牌，牌堆补牌
- 一方要不起，本回合结束
- 胜方优先补牌至 5 张，败方后补
- 一方出完牌且牌堆已空，立即终局
- 终局结算：出完牌者获得桌面和对方手牌中的分值卡
- 分值卡：5=5 分，10=10 分，K=20 分
- 最终比较总分，同分双赢

## 特殊胜利

手牌凑齐 `7、鬼、5、2、3`，直接获胜。

## 压分奖励

出 5/10/K 的单张或对子时，如果和上一手同类型同点数，额外获得本次出牌的分值。

## 功能

- 三档 AI 难度：AI1 简单 / AI2 规则 / AI3 记牌
- 选卡开局：自定义 5 张起始手牌
- 出牌动画、音效
- 游戏日志面板

## 如何运行

### 方式一：下载 Release

1. 打开 Releases 页面
2. 下载 `7gui523-v1.0-win64.zip`
3. 解压到任意目录
4. 双击 `game.exe` 运行

### 方式二：从源码编译

需要：
- Qt 6.11.2
- CMake 3.16+
- MinGW 13.1
- Ninja

编译步骤：

```bash
mkdir build
cd build
cmake .. -G Ninja -DCMAKE_PREFIX_PATH=你的Qt路径
cmake --build .
windeployqt game.exe
./game.exe

# 阶段 A：仅 A1 / A2 / A3

## 改动

- A1：不再读取真实对手手牌内容和真实牌堆顺序来构造搜索世界。按记牌器公开点数计数重建剩余牌堆并随机洗牌；同一个手牌/牌堆假设用于所有候选动作。topK 预筛也只接收对手手牌数和牌堆张数。
- CardTracker 没有记录已出牌花色，因此使用与既有均匀/加权采样器相同的点数等价代表；不在本阶段更改记牌器。
- A2：普通终局将桌面分和对手剩余手牌分给出完者，再比较总分判胜；打出特殊牌的既有直接胜利优先级保留。
- A3：终局直接返回胜 +10000、负 -10000、平 0，不使用非终局启发式估值。
- 未修改 A4/A5/A6、core/rule/、GUI、模块化接口或参数优化器。

- 未编译 Qt GUI（未安装 Qt）；本次修改不涉及 GUI。
